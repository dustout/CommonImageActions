How To Read These Examples

Each example shows the image, the url that made it through the asp.net core middleware, and the code that makes the same image with the fluent API. In the code image is the bytes of the original file and the result is the bytes of the new image. 

using CommonImageActions.Core;
using CommonImageActions.Pdf;
using SkiaSharp;

byte[] image = File.ReadAllBytes("thumbsUp.jpg");

byte[] result = await ImageProcessor.Process(image)
    .Width(100)
    .ToImageAsync();
